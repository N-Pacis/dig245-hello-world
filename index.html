About The Command Line

The Command Line is a tool or text interface that is available on every Operating System. It has a predefined set of commands that you can use to instruct the computer on what to do for you. Additionally, you can create your own command using alias command. For example: alias ll='ls -la'

Another cool thing about the command line, is that you can create files using only commands! Cool, right? You just need to use the touch command. For example: touch test.txt We just created a file named test.txt!

We can also run programs and scripts using the command line. For example if you have a python script named "scraper.py", and you already have python3 installed, you can use python3 scraper.py to run the script!
